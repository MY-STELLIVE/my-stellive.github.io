# STELLINK v1.1.0

v1.0.2 원본 기반 당일 공지·휴방 관리 개편입니다.

## GitHub 업데이트
1. 기존 앱 설정에서 전체 백업을 한 번 내려받습니다.
2. ZIP을 풀고 내용물을 기존 저장소의 동일한 경로에 덮어씁니다. 새 JS 파일도 모두 업로드합니다.
3. assets/members의 공식 프로필은 변경하지 않았으므로 기존 파일을 유지해도 됩니다.
4. 배포가 끝나면 Brave의 스텔링크 탭과 설치한 PWA를 모두 닫고 다시 엽니다. 구버전이 먼저 열리면 잠시 후 다시 모두 닫았다 열어 주세요.
5. 사이트 데이터 삭제는 하지 마세요. 개인 기록은 기존 브라우저 저장소에 있습니다.

## 변경 사항
- KST 오늘 기본 공지 등록, 제목·날짜·원문 링크·메모 수정
- 이미지 선택 후 미리보기·순서 변경·제외, 원본 폭 맞춤 읽기·확대·여러 장 이동
- 날짜별 공지 보관함, 멤버·기간·제목·주간 시간표 필터
- 공지의 멤버·날짜·제목으로 방송 일정 및 휴방 등록
- 예정 시각 LIVE / KST 다음 날 OFF. 실제 치지직 연동 아님
- 하루·기간·종료일 미정 휴방, 복귀 예상 문구, 원본 공지 연결
- 주·월 경계를 잇는 휴방 막대, 휴방과 방송 충돌 확인 및 예외 방송
- 홈 전체 버튼 제거, 멤버 재선택으로 해제, 빈 다음 일정 축소, 최근 공지 3건
- KST 초 단위 시계, 별과 연결 고리 심볼 및 앱 아이콘

## 데이터 보존
DB 이름과 기존 이미지 저장 구조를 유지합니다. 새 기능은 같은 트랜잭션 저장 경로를 사용합니다.
주차만 있던 공지는 기존 주간 공지로 보존하며 날짜를 추정하지 않습니다.
기존 하루 휴방은 원본 일정·이력·연결을 포함한 휴방 기록으로 이전합니다.
이전은 반복 실행 시 중복 생성하지 않습니다. 구버전 백업을 가져올 때도 같은 규칙을 적용합니다.
새 백업은 구버전 앱으로 복원하지 마세요.

## 확인 범위
기존 코어 검사 19개 및 자동 상태·휴방 경계·이전 반복·백업 호환 검사 통과.
주·월 경계의 휴방 막대와 주요 화면 HTML 생성, JS 문법 및 캐시 파일 목록 확인.
이 실행 환경에는 테스트용 브라우저가 없어 실제 Android/Brave 조작 및 시각 검수는 수행하지 못했습니다.

## 주요 파일
core.js: 날짜·백업 검증·데이터 이전
storage.js: 기존 IndexedDB 및 이미지 트랜잭션
schedule.js: 시간 기준 상태 및 휴방 충돌
breaks.js: 휴방 등록·상세·수정
calendar.js: 달력과 기간 막대
notices.js: 공지 등록·보관함·상세
image-viewer.js: 원본 이미지 보기
features.js: 새 기능 동작 연결
app.js / view-state.js / style.css: 기존 화면 기반 통합
