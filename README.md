# STELLINK v1.0.2

## 적용
압축을 풀어 기존 index.html과 같은 위치에 모든 파일과 assets 폴더를 업로드하세요. members.js와 icons.js도 포함해야 합니다. 배포 후 기존 스텔링크 탭과 설치 앱 창을 모두 닫고 다시 여세요.
같은 사이트 주소·브라우저를 유지하면 기존 일정, 이미지, 프로필을 이어서 사용합니다. 브라우저 데이터 삭제는 필요하지 않습니다. 업데이트 전 기존 전체 백업을 보관할 수 있습니다.

## 변경 사항
- 홈 멤버 편집·추가·즐겨찾기 순서 UI 제거. 1~4기 14명을 고정 순서로 표시합니다.
- 14명 전체 활동명과 공식 치지직 채널 프로필 이미지 적용. 기존 사용자 사진은 유지하며 프로필에서 공식 기본 사진으로 되돌릴 수 있습니다.
- 일정·이미지 공지의 멤버 선택을 작은 스크롤 목록으로 변경했습니다.
- 방송 제목 대신 선택 입력인 공지 제목을 사용합니다. 비워두면 일정 공지로 저장하며, 휴방은 휴방으로 저장합니다.
- 제목 공란 때문에 저장이 차단되던 조건 제거. 오류는 입력창 안에 표시하며 저장 중 중복 입력을 막습니다.
- 이미지 공지를 주별/전체 보기, 제목·멤버 검색, 미리보기 카드로 정리했습니다. 공지 제목 수정, 이미지 수정본과 연결 일정 관리를 제공합니다.
- 설정의 긴 사용 안내·소개 문구 제거. 화면 설정과 백업·복원 기능은 유지합니다.
- 하단 메뉴를 홈·일정·멤버·설정으로 변경하고 SVG 선형 아이콘을 적용했습니다.

## 확인 범위
- 핵심 데이터 자동 검사 19건 통과.
- 브라우저에서 제목 없는 일정 추가, 제목을 비운 일정 시간 수정, 새로고침 후 유지 확인.
- 작은 멤버 선택 목록과 공식 프로필 표시 확인.
- 실제 Android Brave 기기 검사는 수행하지 않았습니다.

## 데이터 및 이미지
기존 IndexedDB 구조와 멤버 ID를 유지합니다. 기존 백업도 계속 복원할 수 있습니다.
공식 이미지 원본과 출처 기록은 assets/members/sources.json에 있습니다. 2026-10-29 확인 당시의 이미지이며 자동 갱신되지는 않습니다.
이 앱은 개인용 비공식 팬 도구이며 실제 LIVE 조회·이미지 자동 인식·서버 동기화는 없습니다.
