# STELLINK v1.4.0

## 적용 내용
- 홈·라이브·캘린더·멤버 하단 탭 및 상단 설정, 일정 등록 버튼.
- 라이브 가로 목록형 / 큰 카드형 전환, 보기 선택 기억.
- 두 보기 모두 썸네일 표시. 실제 시청자 수 내림차순 고정, 동률은 멤버순, 미확인 수치는 뒤에 표시.
- 방송 정보: `307명 시청 중 · 00:16:19 스트리밍 중`.
- 진행 시간은 화면이 보이는 동안 매초 텍스트만 갱신합니다. 24시간이 넘어도 누적 시간을 표시합니다.
- 시작 시각 누락·미래 시각은 진행 시간을 표시하지 않습니다. 시청자 수 누락은 확인 중으로 표시합니다.
- API의 실제 방송 판정을 공통 사용. 휴방 저장 직전 응답은 차단하고 이후 방송 확인 시 충돌 안내.
- 추가 API 정보 및 PWA 캐시 버전 갱신. 기존 개인 데이터 마이그레이션 유지.

## 업로드 순서
1. 기존 앱에서 백업을 받습니다. 사이트 데이터는 삭제하지 않습니다.
2. Cloudflare의 기존 Worker 코드를 cloudflare/worker-mobile.txt 또는 worker.mjs 내용으로 교체하고 배포합니다. 둘은 동일합니다. 기존 Secret은 유지합니다.
3. v1.3.6에서 업데이트할 경우 github-update-only **안의 내용**을 GitHub 저장소의 같은 경로에 덮어씁니다. 전체 파일이 필요하면 github 안의 내용을 사용합니다.
4. github-update-only 폴더 자체나 cloudflare, tests 폴더는 Pages에 올리지 않습니다.
5. Pages 배포 후 Brave/PWA를 닫았다 다시 열고 업데이트 안내를 적용합니다.

## 검증 범위
Node 테스트 9개 통과: API·캐시 실패·재시도·휴방·자정·데이터 보존·UI 두 보기·시청자 정렬·시간 형식.
실제 Android Brave 기기 검증 및 원격 GitHub/Worker 배포는 수행하지 않았습니다.
시청자 수·썸네일·시작 시각 등 추가 필드는 v1.4.0 Worker 배포와 upstream 응답이 필요합니다. 구형 Worker에서 누락된 값을 만들어 표시하지 않습니다.
