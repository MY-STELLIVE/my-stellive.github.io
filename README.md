# STELLINK v1.4.1 — 실시간 썸네일 수정·모바일 카드 정리

## 수정 사항
- 실제 운영 응답의 image_%7Btype%7D.jpg 주소를 image_720.jpg로 정규화합니다. 원본 {type} 형식도 처리합니다.
- 치지직이 제공하는 방송 장면 썸네일 사용. 최신 조회 시각의 분 단위 키로 CDN 이미지를 재요청합니다. 연속 영상이 아니며 치지직 썸네일 생성/캐시 지연은 있을 수 있습니다.
- 이미지 실패 시 프로필 확대 대신 미리보기 준비 중 안내.
- 썸네일 시청자 수는 '9,348명'으로 간결하게 표시.
- 라이브 카드 본문은 중복 시청자 수를 빼고 HH:MM:SS 스트리밍 중 표시.
- 홈 및 상세에서는 '9,348명 시청 중 · HH:MM:SS 스트리밍 중' 유지.
- 홈의 일반 체크 문자 제거, 기존 파트너 배지로 통일.
- 제목의 불필요한 최소 높이와 카드 간 여백 축소.
- 라이브 카드 상세 버튼은 오른쪽 위 ⋯로 이동. 누르면 기존 방송 상세가 열립니다.
- 홈 카드·태그·시청 버튼 축소 및 홈 LIVE도 시청자순 정렬.
- 일정 등록 버튼을 하단바 위 별도 영역에 배치, 버튼 크기 축소.
- 앱/Worker/PWA 캐시 1.4.1로 갱신. 기존 개인 데이터 유지.

## 적용
기존 앱에서 백업 후 진행합니다. 사이트 데이터는 삭제하지 마세요.
1. Cloudflare 기존 Worker를 cloudflare/worker-mobile.txt 또는 worker.mjs 내용으로 교체하고 배포합니다. 두 파일은 동일합니다. Secret은 그대로 유지합니다.
2. v1.4.0 사용자는 github-update-only 안의 파일을 저장소의 같은 경로에 덮어씁니다. assets/brand/live-placeholder.svg도 포함합니다.
3. 전체 업로드는 github 안의 내용을 사용합니다. 폴더 자체를 추가하지 마세요.
4. Pages 배포가 끝나면 Brave/PWA를 닫았다 다시 열고 업데이트 안내를 적용합니다.
웹앱에서도 구형 Worker의 인코딩된 주소를 보정하므로 Worker가 1.4.0인 동안에도 썸네일 수정은 적용됩니다.

## 검증
Node 테스트 9개 통과. 원본/인코딩 주소, 0명, 24시간 초과, 시청자순, 체크 제거, 이미지 대체 처리 검증.
운영 API에서 실제 썸네일 주소 수신, 보정한 720 이미지 HTTP 200 및 JPEG 확인.
360px 브라우저에서 두 보기 전환·방송 장면 이미지 표시·간격 검증. 화면 검증의 제목/시청자 수는 모의 데이터입니다.
실제 Android Brave와 원격 배포는 사용자의 적용 이후 확인이 필요합니다.
