# STELLINK v1.5.0 — 다크 전용 화면·탐색 개편

v1.4.2 브랜드 적용본을 바탕으로 만든 실제 웹앱 코드입니다. 목업이 아니라 기존 일정·공지 저장소와 치지직 조회 코드를 사용합니다. 이번 배포 범위는 홈·라이브·소식·캘린더 화면과 탐색 구조입니다.

## 적용 방법

- 현재 v1.4.2라면 `github-update-only/` 안의 **12개 파일**을 기존 GitHub 저장소의 동일 경로에 덮어쓰세요. 폴더 자체를 새 하위 폴더로 올리는 것이 아닙니다.
- 전체 파일을 사용하려면 `github/` 안의 파일과 폴더를 기존 웹앱 루트에 덮어쓰세요. 기존 브랜드 이미지와 14명 프로필도 포함되어 있습니다.
- 기존 v1.4.1 Cloudflare Worker를 그대로 사용할 수 있습니다. 이번에는 Worker 수정이나 Secret 재입력이 필요하지 않습니다. `cloudflare/`는 기존 서버 코드 사본입니다.
- 업로드 후 Brave의 기존 스텔링크 탭과 설치한 PWA 창을 모두 닫았다가 다시 여세요. 설정의 앱 정보에서 `STELLINK v1.5.0`을 확인할 수 있습니다.
- 새 버전은 진행 중인 입력을 강제로 새로고침하지 않습니다. 기존 창이 열려 있으면 서비스 워커 교체가 대기할 수 있습니다.
- 개인 일정·공지 이미지는 브라우저 저장소에 있습니다. 앱의 전체 백업 기능은 그대로 유지됩니다. 버전 확인을 위해 **사이트 데이터나 저장 공간을 삭제할 필요는 없습니다.**

GitHub 업로드와 실제 배포는 수행하지 않았습니다.

## 변경 내용

| 영역 | 반영 내용 |
|---|---|
| 공통 | 다크 전용. 기존 라이트/기기 테마를 다크로 전환하되 글자 크기·움직임·달력 기본 보기는 보존 |
| 하단 메뉴 | 홈 / 라이브 / 소식 / 캘린더. 멤버는 홈의 프로필 레일과 전체 멤버 버튼으로 접근 |
| 홈 | 작은 방송·예정·휴방 요약, 기수 순서 멤버 레일, 시청자순 라이브 최대 3개, 소식 최대 3개, 예정 일정 최대 3개 |
| 홈 등록 | 작은 등록 버튼에서 일정 등록 또는 소식 보관 선택 |
| 라이브 상단 | 큰 브랜드·영문 제목·갱신 패널 제거. 제목/갱신, 기수, 보기/필터의 세 줄 구성 |
| 라이브 목록 | 가로 목록/큰 카드 유지, 시청자순 고정, 멤버 필터, 작은 썸네일은 `9,348명`, 본문은 `01:00:00 스트리밍 중` |
| 라이브 상세 | 전체 시청자·진행 시간 유지. ⋯ 메뉴에서 방송 정보/링크 복사/치지직 이동 |
| 라이브 갱신 | 스크롤 중 재정렬 유예, 새 썸네일을 먼저 불러온 후 교체. API의 실제 썸네일 사용, 실패 시 프로필 사진으로 대체하지 않음 |
| 소식 | 별도 탭, 방송/휴방/합방/기타 분류, 제목·멤버·메모 검색, 멤버/하트/연결 일정 필터 |
| 소식 상세 | 원본 이미지 전체 화면 읽기, 등록 시각과 공지 기준일 구분, 기존 일정 연결·정보 수정·이미지 관리 유지 |
| 소식 분류 | 새로 등록하거나 정보 수정에서 직접 지정. 이전 공지는 임의 추론 없이 기타로 표시 |
| 캘린더 | 일요일 시작 월/주/일 보기 유지. 중복 소식 탭·등록 버튼 제거. 일 보기 화살표가 7일 대신 1일 이동하도록 수정 |
| 등록 | 캘린더 선택 날짜 반영, 멤버 페이지에서 대상 미리 선택. 일정 등록에서는 이미지 첨부를 기본 해제 |
| 멤버 상세 | 프로필 / 홈·소식·일정 내부 탭. 기존 기록을 공유하고 별도 복제하지 않음 |
| 브랜드 | v1.4.2 심볼·워드마크 유지 |

## 데이터와 API

- 공지 제목과 치지직 실제 방송 제목은 계속 별도 데이터입니다.
- 기존 공지–일정 연결, 이미지, 하트, 개인 메모, 휴방, 캘린더 자료와 백업 구조를 유지합니다.
- `topic`은 공지에 선택적으로 추가되는 분류 필드이며 이전 백업도 읽을 수 있습니다.
- 저장되는 앱 버전 표기를 1.5.0으로 맞췄습니다. 이전 코드가 1.2.0으로 다시 저장하던 부분을 정리했습니다.
- API 키와 서버 설정은 변경하지 않았습니다. 조회 주기, 제한 시 재시도, 두 번의 전체 조회로 OFF 확인, 휴방 적용 시각 판정은 기존 동작을 유지합니다.

## 이번 범위에 포함되지 않은 설계

장기 기획의 모든 항목이 구현된 버전은 아닙니다. 브라우저 재시작 후 이어 쓰는 영구 임시저장, 삭제 후 5초 실행취소, 공지–일정 다대다 연결 모델, 실제 방송과 수동 일정의 명시적 연결, 백업 복원 전 자동 사본, 새 버전 준비 알림은 이번에 추가하지 않았습니다. 기존 확인창·미저장 경고·동시 편집 충돌 보호는 유지됩니다.

카페 자동 수집, OCR, 서버 푸시, 댓글, 장기 방송 통계는 포함하지 않습니다.

## 검증

`TEST-REPORT.md`에 검증 범위와 한계를 적었습니다. `FILE-MAP.json`에는 변경 파일과 전체 웹앱 파일의 SHA-256이 있습니다. `Complete`는 배포에 필요한 전체 파일을 포함한다는 의미입니다.
