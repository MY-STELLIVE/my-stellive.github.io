# STELLINK v1.4.2 브랜드 패치

적용 기준: v1.4.1. 기존 심볼의 연결된 두 별과 궤도, 실버·보라색 워드마크를 유지하고 매끈한 금속·에나멜 질감으로 개선했습니다.

## 적용 방법
1. ZIP을 압축 해제합니다.
2. github-update-only 안의 파일을 기존 GitHub 저장소에 동일 경로로 덮어씁니다. 이 폴더 자체를 업로드하지 마세요.
3. Commit 후 GitHub Pages 배포가 끝나면 Brave의 앱 관련 탭과 설치된 웹앱 창을 모두 닫고 다시 여세요. 첫 방문에서 업데이트를 받은 경우 한 번 더 닫았다가 열면 새 캐시가 활성화됩니다.
4. 설정 → 스텔링크 정보에서 v1.4.2를 확인하세요.

Cloudflare Worker 교체는 필요 없습니다(v1.4.1 유지). API·라이브·일정 기능과 개인 저장 데이터는 그대로입니다. 사이트 데이터 삭제는 하지 마세요. 설치된 PWA의 홈 화면 아이콘 반영 시점은 브라우저/런처에 따라 늦을 수 있습니다.

## 포함 사항
- 실제 투명 배경 심볼·워드마크 및 고해상도 원본
- 64/180/192/512 크기 파비콘·앱 아이콘, 마스커블 안전 영역 적용
- 헤더 로고 비율·크기 조정, 버전 표기·서비스워커 캐시 갱신
- 마이그레이션 허용 목록에 v1.4.2 추가(v1.4.1 설정 보존)

brand-masters는 별도 보관용 원본이므로 저장소에 업로드하지 않아도 됩니다.
이미지는 내장 이미지 생성 도구로 제작했습니다. 제작 지시 요약: 기존 두 별과 궤도·STELLINK 철자를 유지하고, 실버 크롬과 보라색 에나멜의 매끄러운 반사·정교한 베벨을 적용하며, 배경은 투명하게 제작.
