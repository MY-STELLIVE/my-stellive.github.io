STELLINK UPDATE · 1.6.1

익숙한 배지,
더 편해진 공지 작성

2026.11.06

실사용 의견을 반영해 채널 표시와 공지 등록 화면을 다듬었습니다.

  • 파트너 배지 이미지 복원
  • 채널명 줄바꿈과 상태 정렬 개선
  • 이미지 첨부·미리보기·순서 변경 개선
  • 한 명 선택 시 [이름] 제목 자동 입력

파트너 배지를 다시 익숙한 모습으로

채널명 옆의 인증 글자를 기존 파트너 배지 이미지로 복원했습니다. 홈의 채널명과 배지를 한 줄로 맞추고, 오프라인 문구가 같은 높이에 놓이도록 정리했습니다.

이미지 첨부와 제목 입력이 편해집니다

큰 이미지 선택 영역에서 여러 장을 추가하고, 미리보기로 확인할 수 있습니다. 이미지는 눌러 펼쳐 보고 순서를 바꾸거나 삭제할 수 있으며, 최대 10장까지 첨부할 수 있습니다.

이름은 자동으로, 내용은 그대로

새 공지·일정 등록에서 히나 한 명을 선택하면 제목 앞에 [히나]가 붙습니다. 타비로 바꾸면 [타비]로 바뀌며 작성한 제목 내용은 유지됩니다. 여러 명을 선택하면 자동으로 붙인 이름만 빠집니다.

히나 선택 → [히나] 오늘 방송 안내 → 타비로 변경 → [타비] 오늘 방송 안내

기존에 저장한 공지 제목은 변경하지 않습니다. 공지에서 일정을 추가하는 경우에도 기존 제목을 유지합니다.

함께 개선했어요

  • 같은 파일을 다시 선택했을 때 중복 첨부를 방지합니다.
  • 이미지를 읽는 중에는 저장을 잠시 막아 첨부 누락을 방지합니다.
  • 첨부 형식과 크기 오류를 이미지 영역에 안내합니다.
  • 홈의 불필요한 구분선과 등록창의 중첩 스크롤을 정리했습니다.
